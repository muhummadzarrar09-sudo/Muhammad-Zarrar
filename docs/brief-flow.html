Client-controlled handoff

One pre-filled WhatsApp message opens.

Nothing is posted to a server. The visitor explicitly opens WhatsApp with the project facts pre-filled, then sends it themselves. The promised response is a written reply within 24 hours: recommended work, timing and an honest range — or an honest no.

WhatsApp packet

These are the exact categories prepared for the builder.

  • Contact — name, business, WhatsApp
  • Starting point — current website / Instagram, or starting fresh
  • Project — selected project type
  • Outcome — the customer action that matters
  • Scope — likely size of the job
  • Readiness — content / asset situation
  • Timing — launch window
  • Budget — approved range or not confirmed

Deliberately not collected

No account, no email-marketing opt-in, no payment information, no invisible server submission and no third-party form embed. The temporary draft stays in the current browser tab until the visitor sends the WhatsApp message.
